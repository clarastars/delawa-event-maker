# Navigation & Tool Rules

- **No Exploratory Shell Commands:** Do NOT run `ls`, `find`, or `dir` commands to discover the repository structure. Use the indexed codebase search or `glob` tool instead.
- **Direct Target Editing:** If the target file path is known, read or edit it immediately. Do not list surrounding directories first.
- **Context Search First:** For conceptual questions ("Where is X handled?"), query the codebase index rather than grepping or listing files manually.
